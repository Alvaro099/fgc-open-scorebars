🚀 1. Quick Start & OBS Studio Setup

Step 1 — Add the 3 Overlays as OBS Browser Sources (1920×1080)

Add each URL to its own OBS Scene as a Browser source set to Width: 1920, Height: 1080, empty Custom CSS:

🎛 Scorebar (Gameplay): http://localhost:8787/
⚔️ VS Splash (Up Next): http://localhost:8787/vs.html
🏅 Results (Top 8 / Podium): http://localhost:8787/results.html

Step 2 — Zero-Flicker OBS Native Transitions

  1. UNCHECK "Refresh browser when scene becomes active".
  2. UNCHECK "Shutdown source when not visible".
  3. Set Page permissions to "Read access to OBS status information".
  4. Adjust Entry Delay (OBS Stinger Sync) in Style Studio → FX & Transitions so your overlay lands right after your stinger clears.

Step 3 — OBS Custom Dock & Mobile LAN Control

  • OBS Dock: Docks → Custom Browser Docks… → paste http://localhost:8787/panel.html. Narrow docks (≤ 1320px) automatically collapse the Designs sidebar into a tab.
  • Phone / Co-Producer LAN: Share the Wi-Fi URL from the OBS tab so a caster or second PC can update scores live in under 5 ms.

🏆 5. Start.gg, Challonge, Match History & Token Privacy

🔒 Stream-Safe Token Privacy: By default, API tokens live only in RAM for the current session and are never written to disk unless you explicitly check Save Token on PC. Zero token characters are ever displayed in the UI, data/ is strictly gitignored, and 🗑 Clear Token erases everything in 1 click.

Start.gg & Challonge Workflow

  1. Get a free token from Start.gg Developer Settings or Challonge Developer Settings (or use ⚡ Demo Tournament offline).
  2. Paste your Tournament/Event URL + Token and click 🔌 Connect.
  3. Click 👥 Import Entrants to cache all players, flags & profile photos locally.
  4. Load sets from Stream Queue in 1 click, update scores, and click 📤 Report Result — side swaps are handled automatically!

Match History & Head-to-Head

  • Every reported or saved set is recorded locally in data/history.json.
  • Live Head-to-Head (H2H) automatically appears on the Active Match Bar and inside the VS Splash screen.
  • Export full tournament match logs as JSON or CSV anytime.
